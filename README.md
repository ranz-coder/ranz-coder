*   **🛡️ Cyber Security & Penetration Testing (The Java Path):** 
    Saya secara intensif mempelajari **Java** bukan hanya untuk pengembangan *backend*, melainkan untuk keperluan **Penetration Testing**. Java adalah tulang punggung banyak aplikasi *enterprise* dan aplikasi Android (APK). Menguasai Java memungkinkan saya untuk melakukan *reverse engineering*, menganalisis kerentanan (*vulnerability assessment*), dan menulis *custom exploit* atau *payload* untuk mengaudit keamanan sistem secara mendalam.

    Saya mengembangkan bot dan antarmuka *gateway* WhatsApp tingkat lanjut menggunakan library **Baileys** (`@whiskeysockets/baileys`) dan **neoxr**. Sistem ini dirancang untuk menangani ribuan *request* secara simultan, di-*hosting* pada lingkungan Linux, dan dipantau 24/7 menggunakan manajer proses **PM2**.

*   **🌐 The Armbian STB Homelab:** 
    Saya tidak hanya menyewa server; saya membangun infrastruktur saya sendiri. Memanfaatkan perangkat *low-spec* seperti **Armbian Set-Top Box (aml-s9xx-box)** dan berbagai VPS, saya melakukan *self-hosting* untuk *environment* pengembangan saya. Semuanya diamankan di balik *reverse proxy* **Nginx** dan dijalur-amankan melewati **Cloudflare Tunnels** agar tidak terekspos langsung ke internet publik.

*   **🎮 Game Server Defense Systems:** 
    Mengelola server **Minecraft Crossplay (Java & Bedrock)** berskala besar. Tantangan terbesarnya bukan pada *gameplay*, melainkan pada infrastruktur. Saya merancang arsitektur server, *proxy routing*, serta merumuskan mitigasi **Anti-DDoS (Layer 4 & Layer 7)** untuk memastikan *uptime* server tetap stabil meski di bawah serangan *botnet* atau *flood*.
