### 👨‍💻 Tentang Saya

- 🔭 Saya adalah **Full-Stack Developer** dan **3D Animator** yang terbiasa membangun antarmuka interaktif menggunakan **Next.js (App Router)**, **React**, **Vite**, dan **Tailwind CSS**.
- 🤖 Sering mengembangkan dan mengotomatisasi bot **WhatsApp** menggunakan **Node.js, Bun, Baileys, dan neoxr**, serta dijaga tetap *online* 24/7 menggunakan **PM2**.
- 🔒 **Fokus Saat Ini:** Saya sedang mendalami **Java** khusus untuk keperluan **Penetration Testing (Pentest)** dan keamanan siber.
- 🗄️ Berpengalaman mengelola *environment homelab*, *reverse proxy* **Nginx**, dan **Cloudflare Tunnels** di atas perangkat keras ringan seperti **Armbian STB** maupun VPS Linux.
- 🚀 Melakukan *deployment* aplikasi *frontend* secara rutin di **Vercel**.
- 🎮 Mengelola server *crossplay* **Minecraft (Java & Bedrock)** dengan kustomisasi *plugin*, sistem ekonomi, dan *hologram*.
